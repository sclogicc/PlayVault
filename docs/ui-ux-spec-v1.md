# PlayVault 界面与交互规范 v1

## 1. 设计目标

PlayVault 的界面不应像企业后台，也不应像游戏平台商店。  
它更应该像一个长期陪伴用户的“个人游戏档案馆”。

设计目标：

- 清楚
- 稳定
- 安静
- 有收藏感
- 便于长期浏览和整理

## 2. 视觉方向

### 2.1 整体气质

推荐视觉气质：

- 沉静
- 稍微偏收藏馆
- 强调内容而不是装饰
- 让截图和游戏信息成为主角

### 2.2 色彩建议

推荐方向：

- 主底色：深灰、石墨、煤灰
- 内容底：略浅一层的深中性色
- 强调色：青绿、冷金、暗红三选一作为主强调色

避免方向：

- 大面积紫色系
- 强霓虹赛博风
- 大面积纯黑 + 高饱和发光
- 过度米黄复古风

### 2.3 字体气质

方向建议：

- 标题稳重
- 正文可读性优先
- 数字信息要清楚，尤其时长和日期

### 2.4 内容优先级

在视觉上必须优先突出的内容：

1. 游戏名称
2. 总时长
3. 最近游玩时间
4. 截图缩略图
5. 待整理提醒

## 3. 布局结构

推荐采用三段式信息结构：

- 左侧导航
- 中央主工作区
- 右侧详情区或操作区

### 3.1 左侧导航

固定导航项：

- 总览
- 游戏库
- 截图箱
- 时间线
- 设置

### 3.2 中央主区

用于承载当前页面主要信息，例如：

- 总览统计
- 游戏列表
- 截图瀑布流或网格
- 时间线记录

### 3.3 右侧详情区

用于展示当前选中对象的上下文信息，例如：

- 选中游戏的信息
- 选中截图的元数据
- 选中 `session` 的详情

## 4. 页面设计要求

### 4.1 总览页

总览页应给用户三个即时答案：

- 我最近玩了什么
- 我总共花了多少时间
- 我还有多少截图没整理

模块建议：

- 顶部三块核心统计卡：今日、本周、本月
- 最近在玩的游戏列表
- 最近新增截图带缩略图
- 待整理截图提示区
- 活跃游戏排行

总览页不要做成营销式首页，不需要大 hero 区。

### 4.2 游戏库页

重点不是“展示很多花哨封面”，而是“快速浏览和筛选”。

推荐视图：

- 列表视图为主
- 卡片视图可作为补充

每项至少显示：

- 游戏名
- 状态
- 总时长
- 最后游玩时间
- 截图数

### 4.3 游戏详情页

这是 PlayVault 的核心页面之一。

页面结构建议：

1. 顶部头部区
- 游戏名
- 状态
- 标签
- 总时长
- 最后游玩时间

2. 中部双栏区
- 左侧：`session` 列表
- 右侧：截图墙或最近截图

3. 下方补充区
- 备注
- `exe`
- 别名
- 文件夹名

### 4.4 截图箱

截图箱不是普通文件管理器，而是“整理中心”。

建议结构：

- 顶部标签切换：待整理 / 已归类 / 已忽略
- 主体：截图网格
- 侧边：当前截图信息与操作按钮

必须支持：

- 多选
- 批量归类
- 忽略
- 打开文件位置
- 复制或移动

### 4.5 时间线

时间线应以“按天回看”为主。

每一天建议展示：

- 当日总时长
- 玩过的游戏
- 每条 `session`
- 该天截图缩略摘要

### 4.6 设置页

设置页要清楚，不要藏太深。

建议分组：

- 路径设置
- 监听设置
- 系统行为
- 数据管理

## 5. 交互原则

### 5.1 系统反馈要明确

用户执行这些动作时，系统必须有明确反馈：

- 新截图已发现
- 截图已自动归类
- 截图已进入待整理
- `session` 已结束
- 文件已复制或移动

### 5.2 危险操作要可撤回或二次确认

以下操作建议二次确认：

- 删除 `session`
- 删除游戏
- 移动原始截图
- 批量忽略截图

### 5.3 不确定状态要可见

系统不应掩盖不确定性。  
比如截图无法判断归属时，应明确标记为“待整理”，而不是假装已成功处理。

## 6. 关键交互流程

### 6.1 新截图归类后的用户感知

推荐流程：

1. 用户截图
2. 系统在后台发现新图
3. 若归类成功，显示轻量提示
4. 若归类失败，待整理数量增加
5. 用户下次打开截图箱时能一眼看见

### 6.2 手动整理截图

推荐流程：

1. 用户进入待整理
2. 选择一张或多张截图
3. 选择目标游戏
4. 归类成功
5. 可选复制或移动到归档目录

### 6.3 查看某次游玩记录

推荐流程：

1. 用户打开游戏详情或时间线
2. 点击某条 `session`
3. 右侧显示本次游玩详情
4. 若存在关联截图，则展示截图缩略图

## 7. 组件建议

建议重点设计好的组件：

- 时长统计卡
- 游戏列表项
- 截图缩略卡
- `session` 时间条目
- 状态标签
- 待整理提醒条

## 8. 文案风格

文案风格应：

- 克制
- 清楚
- 少解释，多结果

避免：

- 过度拟人化提示
- 太像游戏平台营销文案
- 太像企业管理后台术语

## 9. v1 视觉边界

v1 不需要：

- 炫技动效
- 复杂 3D
- 大量动画背景
- 装饰性强于信息性的布局

v1 应该优先把：

- 统计看明白
- 截图看舒服
- 整理路径看清楚

做到位。
