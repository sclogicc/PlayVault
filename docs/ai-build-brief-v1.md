# PlayVault AI 开发简报 v1

## 1. 项目一句话

PlayVault 是一个面向 Windows 单机玩家的本地桌面应用，用于自动记录游戏游玩时长，并半自动整理 NVIDIA 游戏截图。

## 2. 绝对不能偏离的产品定义

1. 这是桌面工具，不是纯网页应用。
2. 这是本地单用户工具，不做账号系统。
3. 核心数据必须保存 `session`，不能只保存总时长。
4. 自动计时规则已经确定：
- 游戏进程启动即开始
- 进程退出即结束
- 只要进程活着就持续计时
5. v1 游戏识别按 `exe` 文件名为主。
6. 截图来源以 NVIDIA 截图目录为主。
7. 截图归类主逻辑依赖“截图时间匹配 `session`”，不是依赖文件名或图像识别。
8. 默认只建立截图索引，不自动移动原始文件。
9. 归类不确定的截图必须进入“待整理”，不能强行归类。

## 3. v1 必做功能

1. 游戏库管理
2. `exe` 绑定
3. 自动生成 `session`
4. 总览统计
5. 截图目录监听
6. 自动归类新截图
7. 待整理截图列表
8. 手动归类截图
9. 游戏详情页
10. 时间线

## 4. v1 不做功能

1. 云同步
2. 社交功能
3. 自动识别通关
4. 平台成就同步
5. 图像内容 AI 识别游戏
6. 复杂图片编辑器
7. 手机端

## 5. 页面结构

1. 总览
2. 游戏库
3. 游戏详情
4. 截图箱
5. 时间线
6. 设置

## 6. 数据实体

1. `Game`
2. `GameExecutable`
3. `Session`
4. `Screenshot`
5. `AppSetting`

## 7. 关键产品原则

1. 自动优先
2. 不确定不硬判
3. 安全优先
4. 明细优先
5. 本地优先

## 8. 推荐开发顺序

1. 数据模型
2. 游戏库
3. 进程监听与 `session`
4. 截图监听
5. 截图归类与待整理
6. 总览与时间线
7. 托盘、自启动、导出

## 9. 交付时必须满足的体验

1. 用户启动游戏后不用手动点开始。
2. 用户退出游戏后自然形成一条游玩记录。
3. 大部分新截图能自动被识别或进入待整理。
4. 用户能在一个游戏详情页同时看到时长和截图。
5. 用户能信任系统不会乱动原始截图。
