# 游戏媒体与游戏库导航改造计划

**目标：** 将游戏封面、详情背景图和游戏库导航调整为清晰、稳定的个人游戏档案体验。

**范围：**

1. 游戏封面使用独立的 `2:3` 图片与裁切参数。
2. 详情背景图使用独立的 `16:9` 图片与裁切参数。
3. 修复裁切弹窗在详情页刷新时重置滑块状态的问题。
4. 侧边栏游戏库取消状态分组，点击进入全部游戏封面总览，展开后显示全部游戏名称。
5. 游戏库总览取消状态分组筛选，保留搜索和排序。
6. 保留新截图在唯一活跃 Session 下自动归类的实现。

**不在本次范围：** 平台账号同步、Playnite 插件体系、模拟器管理、AI 识图、前台窗口识别、游戏元数据联网抓取。

## 任务 1：稳定裁切编辑器

- 为裁切初始化参数建立稳定的重置键，避免活跃 Session 的时钟刷新重置用户正在调整的滑块。
- 保持打开弹窗、切换图片、切换裁切比例时可以正确加载已保存的参数。
- 添加回归测试：相同裁切数据生成相同重置键。

## 任务 2：分离封面与背景图数据

- `cover_path` 与 `cover_crop` 继续表示游戏库竖版封面。
- 新增 `background_path` 与 `background_crop`，表示详情页横向背景图。
- 新增数据库迁移，不删除既有 `banner_crop` 字段，避免破坏已安装用户的数据；新界面不再使用该旧字段。
- 贯通 Repository、IPC、Preload、共享类型和 React 数据更新类型。

## 任务 3：调整游戏详情页媒体区

- 顶部展示独立背景图；无背景图时显示默认渐变。
- 信息区展示独立 `2:3` 游戏封面。
- 提供“设置/调整/移除封面”和“设置/调整/移除背景图”两组明确操作。
- 保存一类媒体时不得影响另一类媒体。

## 任务 4：重构游戏库导航与总览

- 侧边栏“游戏库”标签跳转到全部游戏页面。
- 展开后显示一份按名称排序的完整游戏列表，不再按状态分组。
- 游戏库页面固定展示全部封面墙，移除状态筛选，保留搜索和排序。
- 状态继续作为游戏详情与封面卡片的辅助信息，不作为导航结构。

## 任务 5：保留截图自动归类

- 新进入监听目录的截图在唯一活跃 Session 存在时，自动写入该游戏与该 Session。
- 初始历史扫描和无法判断归属的截图继续进入待整理。

## 验收标准

- 活跃 Session 每秒刷新时，裁切滑块仍能连续改变预览。
- 封面和背景图分别保存、分别删除、互不影响。
- 点击侧边栏游戏库可进入全部游戏封面墙；展开时只出现一份游戏列表。
- 新 NVIDIA 截图在唯一活跃 Session 下不再进入待整理。
- 测试、类型检查、生产构建与差异检查全部通过。
