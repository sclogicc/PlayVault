# PlayVault AI 交接提示词 v1

## 1. 文档用途

本文档提供可直接复制给其他 AI 的开发提示词，目标是减少你手动组织需求的成本，并降低 AI 擅自扩展功能的风险。

使用前建议先同时提供以下文档：

- `docs/product-freeze-v1.md`
- `docs/ai-build-brief-v1.md`
- `docs/prd-v1.md`
- `docs/development-task-breakdown-v1.md`

## 2. 第 1 轮开发提示词

```text
你现在负责开发 PlayVault v1 的第 1 轮功能。

项目背景：
PlayVault 是一个面向 Windows 单机玩家的本地桌面应用，用于自动记录游戏游玩时长，并半自动整理 NVIDIA 游戏截图。

你必须严格遵守以下文档：
- docs/product-freeze-v1.md
- docs/ai-build-brief-v1.md
- docs/prd-v1.md
- docs/development-task-breakdown-v1.md

本轮只允许实现以下任务包：
- 任务包 1：项目基础骨架
- 任务包 2：数据模型与本地存储
- 任务包 3：游戏库管理

本轮目标：
- 建立可运行的 Windows 桌面应用基础结构
- 落地本地数据库和核心数据模型
- 完成游戏库新增、编辑、启用/停用、exe 绑定等核心管理能力

强约束：
1. 不要实现自动计时
2. 不要实现截图监听
3. 不要实现云同步
4. 不要把项目做成纯网页应用
5. 数据模型必须包含 Game、GameExecutable、Session、Screenshot、AppSetting

完成后请输出：
1. 本轮完成了哪些功能
2. 哪些功能故意没有做
3. 当前项目结构说明
4. 下一轮最适合继续做什么
```

## 3. 第 2 轮开发提示词

```text
你现在负责开发 PlayVault v1 的第 2 轮功能。

你必须严格遵守以下文档：
- docs/product-freeze-v1.md
- docs/ai-build-brief-v1.md
- docs/prd-v1.md
- docs/development-task-breakdown-v1.md

在保留现有代码结构的前提下，本轮只允许实现以下任务包：
- 任务包 4：进程监听与 Session 记录
- 任务包 7：游戏详情页

本轮目标：
- 实现按 exe 文件名识别游戏进程
- 实现进程启动即开始计时、进程退出即结束计时
- 自动生成 session
- 在游戏详情页展示总时长、最后游玩时间和 session 列表

强约束：
1. 不要加入失焦暂停
2. 不要加入无输入暂停
3. 不要只保存总时长，必须保存 session
4. 不要实现截图归类
5. 不要改动产品冻结文档中的计时规则

完成后请输出：
1. 本轮完成了哪些功能
2. session 相关实现说明
3. 是否存在边界风险
4. 下一轮最适合继续做什么
```

## 4. 第 3 轮开发提示词

```text
你现在负责开发 PlayVault v1 的第 3 轮功能。

你必须严格遵守以下文档：
- docs/product-freeze-v1.md
- docs/ai-build-brief-v1.md
- docs/prd-v1.md
- docs/development-task-breakdown-v1.md

在保留现有代码结构的前提下，本轮只允许实现以下任务包：
- 任务包 5：截图监听与截图入库
- 任务包 6：截图归类与待整理

本轮目标：
- 支持配置 NVIDIA 截图来源目录
- 监听新增截图并写入本地数据库
- 根据截图时间匹配进行中的 session
- 单候选自动归类
- 多候选或无候选进入待整理
- 支持手动归类、忽略、打开原文件位置、手动复制或移动

强约束：
1. 不要依赖文件名进行核心归类
2. 不要使用图像内容 AI 识别游戏
3. 不要默认自动移动原图
4. 多候选时不要自动猜
5. 历史截图导入不属于本轮范围

完成后请输出：
1. 本轮完成了哪些功能
2. 截图归类主链路说明
3. 待整理机制说明
4. 剩余风险和下一轮建议
```

## 5. 第 4 轮开发提示词

```text
你现在负责开发 PlayVault v1 的第 4 轮功能。

你必须严格遵守以下文档：
- docs/product-freeze-v1.md
- docs/ai-build-brief-v1.md

- 完成总览页
- 完成时间线页面
- 完成设置页关键项
- 支持托盘运行

完成后请输出：
1. 本轮完成了哪些功能
2. 总览和时间线实现说明
3. 托盘与导出能力说明
```

## 6. 通用补充提示词

如果你希望其他 AI 在每轮里更谨慎，可以额外加这一段：

```text
请不要为了显得“功能完整”而擅自添加产品文档没有要求的逻辑。
如果你发现产品文档存在模糊点，请优先沿用 product-freeze-v1.md 的冻结规则，不要自行扩展解释。
```
